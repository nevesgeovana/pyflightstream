# Python API

Every public name of the package, generated from the docstrings at build time, one page for each of its 163 public modules. A page lists every name of the module's `__all__`; the names a guide or an example uses come first. A subpackage's page carries what it re-exports, and the pages of its modules follow it. The [Python API tutorial](../tutorial-python-api.md) is the place to start, and the [exceptions catalog](../exceptions.md) lists every refusal.

Maturity comes from the package's module maturity table: stable, provisional, experimental or internal. Internal modules are not public and have no rows here. The package-root page is an overview, outside the affirmed public-module inventory. API maturity does not claim solver verification or scientific validation.
