# Contributor graphs

Use these versioned views to locate a requirement and understand the library.
The source registry defines the requirement hierarchy; the graph is its projection.

- [Requirements tree](requirements.md): stable requirement IDs grouped by area and parent.
- [Library module graph](library.md): modules and outgoing imports grouped by layer row.

Regenerate from the repository root:

```console
python scripts/gen_canonical_graphs.py
python scripts/gen_canonical_graphs.py --check
```

The check compares generated bytes with the committed pages and JSON data.
It reports missing or changed artifacts without rewriting them. The tier-1 graph
guard also plants changes to prove that stale artifacts are refused.
