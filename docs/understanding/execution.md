# Execution: a steady-polar experiment

The representative example uses POL 1001, a steady wing and an alpha sweep. This is a **static source trace**, not an executed solver run. Planning, running and explicit post-processing are separate invocations. Ordered rows include nested calls and returns, not a flat timeline of independent operations.

**Limits:** this is a static source trace of one steady-polar scenario, not a solver run or a timing measurement.
