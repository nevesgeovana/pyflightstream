# References

Manual citations use FSM build identifiers. Literature and standards use permanent REF identifiers. Only established metadata is listed; missing fields are omitted. Reference numbers are never reused.

## FlightStream manual editions

Build labels identify the manual shipped with that canonical build. They are not claims that the PDF prints its own build number. Manuals are cited by edition and page; the 25.000 conversion requires its pinned pagination.
