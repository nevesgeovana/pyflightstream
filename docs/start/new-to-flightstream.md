# New to FlightStream and the panel method

FlightStream is a panel method solver. It represents surfaces with panels and
solves for the flow quantities defined by the selected formulation and solver
build. It does not replace geometry preparation, engineering judgment, or
independent validation.

## Stages of a study

| Stage | Workspace task |
|---|---|
| Define the question | Set a reference artifact and flight conditions. |
| Prepare geometry | Import or mesh the surfaces and check units. |
| Configure the study | Select a preset, boundaries, and run type. |
| Plan and run | Preflight the campaign, then execute with a supported build. |
| Review results | Read the recorded products and their evidence. |

The [workspace and workflow](../workspace-and-workflows.md) page explains the
complete route. See [the vocabulary](../definitions/the-vocabulary.md) for
terms used throughout the documentation and the relevant
[PDF guide](https://github.com/nevesgeovana/pyflightstream/tree/main/guide).
