## Fixed

- `RESTART: {ADDITIONAL_REVS=n}` and `{ADDITIONAL_ITERS=n}` now continue an `unsteady` or `unsteady_rotor` point whose latest run CONVERGED, as they continue one its wall clock stopped, so a finished campaign can march the revolutions its averages need without running every point again (FR-96). Until now such a point was passed over in silence and the plan listed it as recorded. The continuation's record states the request it answered under the new key `restart`, written on continuations only: the same request does not continue a point twice, a different one does, and a continuation recorded before 0.33.0 is taken to answer the request its row carries. `{ADDITIONAL_REVS=n}` counts revolutions on the record's own clock where the row exported nothing per step. `{FINISH_PENDING}` on a CONVERGED run is refused with the reason, and every point a `RESTART` key does not continue is now said, in the plan's new `Continuations (RESTART)` block and in the run.
- The averaging window of a continued point now ends at the last step of the whole march (FR-96). The post joins the plots history of every run of the chain, read from the archive each continuation moved it into, by step number, with no step repeated or missing at a seam, and says in `post.log` how it joined them; the plots table, the reductions, the unsteady polar and the rotor table of such a point change accordingly. A point that continues nothing posts byte for byte as before.
