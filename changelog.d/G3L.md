Every `pyfs-geom` run and every doe set now writes `geom-run.log`, a plain-text log beside the stage records, written as the run proceeds. It names the configuration file and the package version, then lists each sub-step in order with its inputs, each check with its measured value, threshold, unit and verdict, its wall time and its warnings, and ends with the sub-step where the run stopped and why, or that it completed, with the sub-steps not reached and the checks not measured. A refused run, and a doe set whose worker faulted or was refused, now leave `report.json` and `geom-run.log` in their set folder; a stage record carries its wall time.

migration: none; the log is a new file in the run folder.
