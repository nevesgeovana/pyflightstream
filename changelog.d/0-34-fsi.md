## Added

- The FSI convergence log `fsi_convergence_log.csv` ends with a new column, `tip_flap_signed_m`: the tip flap deflection in metres with the sign the displacement file `FSIDisp.txt` carries, positive toward the suction side, so a wing bending down under its own weight now reads negative (FR-339). `tip_flap_m` stays the magnitude, and on a rotor both name the blade of largest magnitude. The FSI page states the convention.

## Migration

- A script that reads `fsi_convergence_log.csv` by column name reads a 0.34.0 log unchanged; one that counts the columns of a row sees fourteen instead of thirteen, the new last one being `tip_flap_signed_m` (FR-339). Every earlier column keeps its name, position and value, and a 0.33.0 log is still read as before.
