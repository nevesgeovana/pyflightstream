Added the `pyflightstream.geometry` package: a validated component parameter record (`ComponentRecord`, with an exported JSON Schema and SHA-256 pin check), a TOML geometry configuration boundary (`load_config`, `resolve_config`, `write_config`), NACA and CST sections, spanwise spline distributions, lifting surfaces with root fillet and flat, rounded or ridged tip caps, and the `Patch` exchange type. Pure numpy and scipy; no geometry kernel is imported.
