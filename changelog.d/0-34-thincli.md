## Added

- `pyfs-matrix degenerate GEOMETRY --kind thin-blade --root-offset LENGTH`, beside `inventory`, derives the thin blade of a blade mesh (a saved simulation or an OBJ) and writes it with its boundary inventory beside the source; `thin-blade` is the one kind and the default of `--kind`, the offset is required, `--overwrite` rewrites an existing output, and a refusal exits 2 naming the file and the reason with nothing written (FR-330 R1, R4, R6). The command and its options are in the generated command-line reference and in both pages of the cheatsheet that name the commands (FR-330 R7).
- `--boundary NAME` on `pyfs-matrix degenerate`, and `boundary=` on the library function, names the one boundary (an OBJ's group) that is the blade when the file also holds a spinner, a nacelle or other bodies: only its faces are read, the output is written as `<stem>_<NAME>_thin_blade.obj` with its inventory, and a name the file does not hold, or holds twice, is refused naming what the file holds. Without it a file of several boundaries is refused as before, the message now naming the option (FR-330 R6, R9).
