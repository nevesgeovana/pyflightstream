## Added
- FlightStream 26.125 is a registered build: it resolves as `26.125` (vendor name 26.12), prints its release as `2612` at build `10052026`, and its manual edition (SRC-753) backs a `documented` row for every command it documents; `pyflightstream.support_table()` lists it at level `documented` until its probe campaign runs (FR-423).
- Twelve commands the 26.125 manual documents first enter the command database, each with a probe specification: `ENABLE_SOLVER_TIME_AVERAGING`, `DISABLE_SOLVER_TIME_AVERAGING`, `RESET_SOLVER_SWEEPER`, `STABILITY_TOOLBOX_ANGLE_INCREMENT`, `SET_AEROELASTIC_CONVERGENCE_THRESHOLD`, `CREATE_FREE_SURFACE_TFI_MESH`, `FREE_SURFACE_EXPORT_TYPE`, `DELETE_FREE_SURFACE`, the three `ASSIGN_SELECTED_CURVES_TO_CCS_*` and `SET_CCS_TE_BLEND_LENGTH` (FR-423).
- Setup keys `solver_time_averaging = [first, last]` (unsteady rows, `ENABLE_SOLVER_TIME_AVERAGING`, warned where no run verified it) and `aeroelastic_convergence_threshold` (`SET_AEROELASTIC_CONVERGENCE_THRESHOLD`); `[import.ccs]` key `te_blend_length_pct` (`SET_CCS_TE_BLEND_LENGTH`) and the trailing-edge geometry `ROUNDED_BLEND`; force-plot parameters `CDP` and `CDV` (FR-423).
- `pyflightstream.script.helpers.detect_every_boundary`, `every_boundary_detection`, `takes_every_boundary`, `wake_edge_import_token`, `assign_selected_ccs_curves` and `solver_time_averaging` write a request in the form the target build documents (FR-423).

## Changed
- On 26.125 the raw-mesh `detect = "auto"` detections, and the minimal workflow, write the every-boundary (-1) form of `DETECT_TRAILING_EDGES_BY_SURFACE`, `DETECT_BASE_REGIONS_BY_SURFACE` and `DETECT_WAKE_TERMINATION_NODES_BY_SURFACE`, since its manual prints no `AUTO_DETECT_*` command; the wake-edge import writes EDGE_TYPE `1` as its third token; and the CCS curve route assigns the selected curves to the component (FR-423).
- The output readers accept the 26.125 export title and footer (`Simcenter Flightstream`, release `2612`) and its loads header (FR-423).

## Migration
- Nothing to change for 26.124 and earlier: every script, record and product of a build other than 26.125 is byte-identical (FR-423).
- To run on 26.125, add its executable to the machine's executables configuration under `26.125` and run the probe campaign of the release before relying on a `documented` command (FR-423).
