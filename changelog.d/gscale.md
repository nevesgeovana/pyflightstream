`pyfs-workspace geometry scale <factor> --mesh <file>.obj [--out <folder>] [--about x,y,z] [--force]` scales every vertex of an OBJ uniformly about the origin or a point, writing the scaled OBJ under the input name and a `<name>.scale.json` record (input hash, factor, centre, counts, bounding boxes before and after) into an output folder it creates (default `<stem>_scaled<factor>` beside the input). Face order, groups, normals and comments are unchanged byte for byte; the input is never overwritten, and a zero, negative or non-numeric factor, a missing file and an existing same-name output without `--force` are refused. The Python entry is `pyflightstream.workspace.scale.scale_mesh` (PFS-2222).
