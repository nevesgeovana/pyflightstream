`pyfs-workspace geometry scale <factor> --mesh <file>.obj|<file>.fsm [--out <folder>] [--about x,y,z] [--force]` scales every vertex of an OBJ, or every node of a FlightStream .fsm, uniformly about the origin or a point, writing the scaled file under the input name and a `<name>.scale.json` record (input hash, factor, centre, counts, bounding boxes before and after) into an output folder it creates (default `<stem>_scaled<factor>` beside the input). The format follows the file suffix. For an OBJ, face order, groups, normals and comments are unchanged byte for byte; for an .fsm only the x, y and z node rows of the mesh block change and every other byte, line endings included, is kept (a `<stem>.boundaries.toml` beside it is not copied). The input is never overwritten, and a zero, negative or non-numeric factor, a missing file, an .fsm without a mesh block and an existing same-name output without `--force` are refused. The Python entry is `pyflightstream.workspace.scale.scale_mesh` (PFS-2222).
