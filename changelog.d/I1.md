## Changed

- The documentation site is organized by task (GEO-066 2.1, package I1, no FR id: it adds no capability). The nav has five groups in this order: Getting started, Workflows, Post-processing, Reference, Migration. Every page keeps its content; the release notes and every `migrating-to-*` page are under Migration, and the post-processing definitions stay one page under Post-processing.
- The workspace and workflow guide, `docs/workspace-and-workflows.md`, is now the index of the Workflows group, and each run type and topic it held has a page of its own: the run matrix, the steady, unsteady, unsteady rotor and quasi-steady rotor workflows, the input library and the solver presets, the reference artifact, one row with an actuator disc or a custom free stream, one row with a geometry turned or moved, planning and cost, builds and clusters, the additional post, and the post-processing artifact and its products. Each fact has one home and the other pages link to it.

## Migration

- A link or a bookmark to `workspace-and-workflows.md#<section>` for a section that moved now lands on the index page. Follow the table on that page to the page that holds the section; the anchor of every section is unchanged, so `<page>.md#<section>` works on the new page.
