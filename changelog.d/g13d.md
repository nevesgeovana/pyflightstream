A named IGES file written by the package now imports directly into the solver's CAD import: every curve a trimming boundary (142) names in parameter space, and each member of its composite, carries entity use flag 05 (2D parametric), and the 142 itself 00. A face the kernel would write with no parameter-space outer boundary (a surface's natural boundary, or a plane or other analytic surface) is written as a B-spline copy that carries one; the copies leave the model after the write. A boundary that states PREF 2 (model space preferred) is still written as asked, and the solver reads no face from it.
