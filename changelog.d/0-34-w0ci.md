## Changed

- The development version is 0.34.0.dev0 (no requirement: opening the 0.34.0 development cycle); the decks and the user guide cover state the base version 0.34.0.
- The release workflow also runs on a push to a branch named `dry-run/**`: build, the wheel tests on both runners and the release gates run as they do for a tag, and the tag-to-version check and the publish job run only for a `v*` tag, so a release is rehearsed before any tag exists (no requirement: release tooling, P0340-RELEASE-TITLE arm CI).

## Fixed

- The report-index test of the licensed probe round reads the change log section that carries its report by the report's identifier, so opening a new release section, empty or not, no longer fails it (FR-345).
