## Changed

- A bare matrix name or stem found in the workspace's root or `inputs/matrices/` is the matrix of every command, `rebuild` included: a same-named file in the working directory is no longer read and no longer refuses the command; when its bytes differ, a WARNING names both files and says the workspace's was read (FR-411).

## Fixed

- `pyfs-matrix rebuild` no longer refuses every simulation of a matrix kept in `inputs/matrices/` that has a `RUN 0` row as being "in both homes of the workspace with different content": its throwaway copy held the matrix twice, once re-activated (FR-411).

## Migration

- A command run from a folder that holds a different file of the matrix's name now reads the workspace's matrix with a WARNING instead of stopping. To read the other file, name it with its folder, for example by its absolute path (FR-411).
