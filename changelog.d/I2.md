## Added

- The user guide lists the two commands 0.32.0 added to `pyfs-matrix`, `restore` and `rebuild`, in its cheat sheet of the command-line tools, so the page that enumerates the surface no longer leaves a subcommand out (no requirement: documentation of two commands whose requirements their own package owns).
- `docs/gui-to-pyfs.md` has a line for the CCS geometry route (`CCS_SHEDDING` and the `[import.ccs]` table) and for the five acoustic keys of an unsteady row, so every registered row key has its GUI step (no requirement: documentation of keys the packages added).
- `docs/field-operations.md` teaches `field fill-interior`, `field time-mean --fluctuation`, `--fluctuation-only` and `--vinf`, which the page left out (no requirement: documentation of the inflow tools, whose requirements their package owns).
- `docs/post-processing-definitions.md` states every column of the acoustic tables (pressure, spectrum, summary, blade-passage harmonics, directivity), their manifest entry (`kind` `acoustics`) and their skips, says that the VTK files of an acoustic section are recorded outputs and not a table, names the `out=` and `flip=` arguments of the installed-frame copy, and lists the sections of 0.32.0 in its contents (no requirement: the definition of record, where the code was ahead of the page).

## Fixed

- Two listings of the user guide called `helpers.probe_points` and `helpers.probe_line` with a `units` keyword they do not take, so both raised `TypeError`; the keyword is removed from the guide (the API is unchanged, no requirement: a documentation defect found on 0.31.0). A test now binds every `helpers.<name>(...)` call of the guide's listings to the helper's signature.
- `docs/gui-to-pyfs.md` said "not yet" for importing probe points from a file (the pproc `[[probes]]` table's `points_file` does it) and for disabling a disc or changing its wake (`actuator_operations` and the reference block's `wake_type` do), and offered the raw setup route for commands that take a block (a keyword block, data lines or parameter lines), which the raw route refuses before anything runs; each such step now says what is and is not reachable (no requirement: documentation accuracy). A test holds that the raw route is offered only for one-line commands.
