A geometry file takes the key names of the published input form: `planform` with `sref_m2`, `aspect_ratio` and `taper` (or `semispan_mm`, `root_chord_mm` and `tip_chord_mm`; the semispan includes the tip cap), `root_le_mm`, `le_sweep_deg`, `dihedral_deg`, a `[surface]` table (`span_axis`, `twist_axis`, `model`, `section_type`), `[[stations]]` (`eta`, `twist_deg`, `section`), `[cap]` (`type`), `[[control]]` (`eta = [inner, outer]`) and `[[engine]]` (`eta_axis`, `half_width_mm`); a file with `[surface]` and no `type` is read as one lifting surface. The earlier names were never released and are refused with the new name. A key without an implementation yet (`[[bay]]`, a cap template, a tabulated flap cove, a B-spline section file, per-station trailing edge thickness) warns by name and is skipped. migration: rename `planform.span`, `height`, `area`, `root_chord`, `tip_chord`, `sweep`, `dihedral`, `orientation` and `twist_axis`, `tip_cap` (with `kind`) and `control_surfaces` (with `eta_in` and `eta_out`) to the names above; give one complete planform set.
