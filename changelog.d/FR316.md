## Added

- A matrix row may state setup keys in its `VAR_NAMES_VALUES` cell under their native names, over the preset its `SET` cell names, for that row only (FR-316). `plan` warns for every row that does, naming the row and the keys; a key the preset does not state, or states with an equal value, is accepted; a key the preset states with a different value is refused, naming the row, the key and both values. Each value is validated by the preset's own loader, and the setup snapshot of the run record lists the row's keys under `from_row`. Table-valued keys are a preset's only.
