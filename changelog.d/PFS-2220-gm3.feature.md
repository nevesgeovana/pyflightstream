The geometry pipeline runs as stages S0 to S13 through `run_geometry` and `run_doe` in `pyflightstream.workspace.geometry_pipeline`: a run stops at the first failed check and returns a report that names its stage and its check, and a loop of parameter sets continues after a failed or refused set, each set in a worker process of its own. migration: none, the entries are new in 0.57.0.
