## Added

- `[[prune_step_exports]]` of a free-space recipe may state `keep_last = K` (keep the last `K` steps of each per-step export) or `delete_steps = [A, B]` (delete the steps `A` to `B` inclusive, keep every other step), never both; a `K` above the steps on disk and a range holding none delete nothing and are no error. The recorded step entry states the key used (FR-416).

## Changed

- Every key of a `[[prune_step_exports]]` table other than `sims`, `status`, `keep_last` and `delete_steps` is now refused before any file is touched, naming the key and the accepted ones (FR-416).
- The refusal of a later post that needs a step `free-space` deleted now says what the call kept ("the last 12 steps of each export only", "every step outside 5 to 9 of each export"); a table that states neither key still reads "the last step of each export only" (FR-416).

## Migration

- A recipe whose `[[prune_step_exports]]` table carried a key the mode never read (for example `older_than_days`) now stops with a refusal that names the key; remove it. A table that states neither `keep_last` nor `delete_steps` deletes and records exactly what it did in 0.36.0.
