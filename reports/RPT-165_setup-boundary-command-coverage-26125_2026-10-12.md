## Method

Generated by `scripts/build_command_coverage.py`. The setup/BC chapter register of `tests/tier1_offline/test_goal034_setup_operational_commands.py` supplies the database categories, with the new `free_surfaces` chapter added for 26.125. The database loader calls its file stem `chapter`; there is no separate category field. Membership follows those files, never command spelling or emission phase.

All entries of those chapters are retained, including an unprobed supplement for names without a 26.125 row. This build has `inherits_base: false` in `commands/_meta.yaml`. Removed, broken and missing-evidence commands are not offered even where another build has a workspace route. Database notes and probe references are preserved in the JSON twin.

Setup routes come from `cases/_setup_keys.py` and explicit reviewed links for matrix, sidecar, reference and pproc inputs. The builder verifies input keys against their source registers, requires executable reads of artifact fields, and finds executable AST emission witnesses, including conditional names and the Row tables consumed by the settings emitter. The workflow settings, setup link, geometry, free-stream, pproc and FSI emitters supply these links through workspace binding and run assembly.

RPT-106 was produced by the union of the six solver database chapters and the 26.124 manual census, with one row per choosable argument and checks in `test_fr319_setup_key_audit.py`. This successor counts commands once. `reachability_exceptions.json` records public API reach exceptions, rather than command exclusions, and does not establish a command route. Generic raw commands and custom flags do not count as named workspace routes.
