# RPT-050: the 26.124 package against the 26.123 package, file by file (2026-09-15)

Amended 2026-09-30: the digests of the two executables are withheld under NFR-31, each row stating its build and size instead. Amended 2026-10-01: the digests of three libraries and the sample script are withheld under NFR-31 (SRS 1.66.0). Amended 2026-10-01: the digests of the user manual (pdf and chm), the release notes and the licence agreement are withheld as well (FR-344), each row keeping its file, size and equal reading; no tracked file carries them from 0.34.0 on, and they stay in the history of the repository. Every other value is as measured on 2026-09-15.

**WHAT THIS SETTLES.** 26.124 was registered on 2026-09-14 by carrying every
26.123 row forward citing its manual, SRC-752, on the ground that the package
ships the 26.123 documentation unchanged and only the executable differs
(`commands/_meta.yaml`, the 26.124 entry and the SRC-752 edition note). That
ground was measured on 2026-09-14 and not written down as digests. This report
writes it down: every file of both installed packages, with its SHA-256 and its
size in bytes, measured on 2026-09-15 on the machine that runs the probes.

**THE VERDICT.** Eight of the eight non-executable files of the 26.124 package
are byte-identical to a file of the 26.123 package. The executable is the one
file that differs. The corpus copies SRC-751 and SRC-752 carry the manual's
digest, which the private corpus keeps.

The digests of the three DLLs and of the sample script are withheld (NFR-31: no digest of a
library, an executable or the sample script of the solver package stands in the public tree),
and so are those of the manual, the release notes and the licence agreement (FR-344); each file
was measured equal between the two packages, which the column "the same" states.

The manual pdf is named `Altair FlightStream User Manual 26123.pdf` in the 26.123
install and `Altair FlightStream User Manual.pdf` in the 26.124 package; the
bytes are the same. The 26.123 install also carries a second copy of its
executable under the alias name `Flightstream_2612.exe`, with the same digest.

The corpus files SRC-751 (the 26.123 edition) and SRC-752 (the 26.124 edition)
both carry the manual pdf's digest, which this report no longer writes (FR-344).

## Where the files came from

- 26.124: the vendor zip `FTS_26124.zip`, ten entries (nine files and a folder),
  extracted into the installation folder the probes use; the files above were
  measured in the extracted folder.
- 26.123: the installation folder the 26.123 probes used since 2026-08-17.

The executable's size, 19197320 bytes, is this report's reading; the digest is
also the one `reports/compat/CMP-26124_2026-09-14.yaml` recorded from the
identity run.

## What this does NOT say

- Identical documentation does not mean identical behaviour: the executables
  differ, and nothing here compares what they compute.
- Nothing here reads inside either executable.
