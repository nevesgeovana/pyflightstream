# RPT-050: the 26.124 package against the 26.123 package, file by file (2026-09-15)

**WHAT THIS SETTLES.** 26.124 was registered on 2026-09-14 by carrying every
26.123 row forward citing its manual, SRC-752, on the ground that the package
ships the 26.123 documentation unchanged and only the executable differs
(`commands/_meta.yaml`, the 26.124 entry and the SRC-752 edition note). That
ground was measured on 2026-09-14 and not written down as digests. This report
writes it down: every file of both installed packages, with its SHA-256 and its
size in bytes, measured on 2026-09-15 on the machine that runs the probes.

**THE VERDICT.** Eight of the eight non-executable files of the 26.124 package
are byte-identical to a file of the 26.123 package. The executable is the one
file that differs. The corpus copies SRC-751 and SRC-752 carry the manual's
digest.

## Where the files came from

- 26.124: the vendor zip `FTS_26124.zip`, ten entries (nine files and a folder),
  extracted into the installation folder the probes use; the digests above were
  read from the extracted files.
- 26.123: the installation folder the 26.123 probes used since 2026-08-17.

The executable's size, 19197320 bytes, is this report's reading; the digest is
also the one `reports/compat/CMP-26124_2026-09-14.yaml` recorded from the
identity run.

## What this does NOT say

- Identical documentation does not mean identical behaviour: the executables
  differ, and nothing here compares what they compute.
- Nothing here reads inside either executable.
