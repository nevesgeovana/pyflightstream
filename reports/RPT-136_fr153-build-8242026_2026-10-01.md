# RPT-136 - Build 8242026 of FlightStream 26.124 is registered by decision, not by measurement (2026-10-01)

The record of the registration that **FR-153** makes for build **8242026** of
FlightStream 26.124. It states what the package does for that build, on whose
word, and what no run has measured. No solver was run to write this report and
no run measured this build.

## 1. The decision

On 2026-10-01 the owner was asked why a comparison run on build 8242026 was
needed before registering it. She answered, in Portuguese:

> "ele escreve, nao precisa avisar"

Read as the decision: build 8242026 writes sampled fields as build 8172026 does,
and the warning that FR-153 R1 adds for an unregistered build is not needed for
it. The decision is the owner's; the package records it as a decision and makes
no claim that a measurement backs it.

## 2. What it lifts

Build 8172026 is the build on which the native velocity convention and the
rotation timing of 26.124 were measured (RPT-083). For build 8242026 the
package now carries one row of each kind that 8172026 has, with the same
values:

| Row kind | Units | Value as 8172026 |
|---|---|---|
| Unsteady fluid plot velocity convention | METER, MILLIMETER | scale 1.0 to m/s, absolute REFERENCE components |
| Steady probe velocity convention | METER, MILLIMETER | scale 1.0 and 0.001 to m/s |
| Rotation timing | METER, MILLIMETER | rotation sense factor 1, STEP time origin 0 |

For a field of build 8242026 in those units the post therefore writes the
field with no warning, `post.log` carries no velocity-convention line, and the
`products.json` entry carries neither `velocity_convention` nor
`rotation_timing`: the proof counts as proven for the build, as it does for
8172026.

## 3. What marks it as a decision

Each of these rows says in its evidence that it is the "owner decision of
2026-10-01, not measured" and cites this report. A measured row carries a
receipt and a comparison instead; a reader can tell the two apart by that
text. The rows of build 8172026 are unchanged, byte for byte.

## 4. What it does not cover

- No run measured build 8242026: no comparison of fixed and turning frames, no
  steady probe comparison, no accuracy claim.
- A delayed motion start still has no timing proof on any build.
- Another solver version, another unit and another export family still have no
  evidence and are refused as before.
- Any other build of 26.124 is still written with the FR-153 R1 warning.

A measurement on this build, if it is ever made, would replace the decision
rows with measured rows and would be recorded in a report of its own. If it
differed from build 8172026 the decision rows would be withdrawn.

  keeps the warning proved on a build nobody registered.
