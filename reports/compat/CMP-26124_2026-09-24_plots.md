# Compat report: FlightStream 26.124 (2026-09-24)

This is a compat-format transcription of the licensed probe T13, reported as
RPT-067 (`reports/RPT-067_the-plot-commands-write-the-plotted-series-as-text_2026-09-24.md`,
evidence `reports/probes/RPT-067_2026-09-24_evidence.yaml`). No solver was invoked
while writing it, and it does not claim a probe-harness execution. The paired YAML
records the same measured numbers and the `verified` outcome for `SET_PLOT_TYPE`
and `SAVE_PLOT_TO_FILE`, from which `pyfs-qa apply-compat` promoted the two 26.124
rows.

| Run | The one addition, after the exports and before `EXPORT_LOG` | Return code | Plot file | What it holds |
|---|---|---|---|---|
| Control | nothing | 0 | none | |
| Residuals | `SET_PLOT_TYPE RESIDUALS`, then `SAVE_PLOT_TO_FILE` with the path on the next line | 0 | 18791 bytes | the velocity and pressure residuals, 181 rows |
| Loads | `SET_PLOT_TYPE LOADS` and the save | 0 | 27395 bytes | lift, induced drag (vorticity) and pitching moment, 181 rows |
| Section Cp | `SET_PLOT_TYPE SECTIONS_CP` and the save | 0 | 49727 bytes | one x/Cp column pair for each of the 12 sections |

The solve converged at iteration 181 in every run, the loads export of each
variant carries the control's `Total` row digit for digit, and the solver printed
nothing between the sentinels around the plot lines. Every run exported its log
after them.

What the promotion does not claim: the other twenty `SET_PLOT_TYPE` tokens, a save
to a relative path (the run wrote to an absolute one), a save before a solve, a
folder that does not exist, an unsteady run, and any build other than 26.124. A
plot is a display of the solve and never a source of a coefficient: the plotted
pitching moment (-0.897) is not the exported CMy (-0.0247).
